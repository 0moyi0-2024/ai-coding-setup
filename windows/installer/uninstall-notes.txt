DeepSeek Harness (DSH) 卸载说明
================================

如果安装过程中失败或需要彻底清理，有 2 种方式：

【方式一：一键清理】（推荐）
  开始菜单 → "清理 DSH（安装失败时使用）"
  或直接运行：powershell -ExecutionPolicy Bypass -File "清理DSH.ps1"
  会自动删除：
    - 桌面快捷方式
    - WSL 内的 DSH 源码 (/home/dsh/dsh)
    - WSL 内的 /agent 目录
    - WSL Ubuntu 发行版
    - 防火墙规则

【方式二：手动清理】
  1. 删除 WSL Ubuntu 发行版：
     wsl --unregister Ubuntu-24.04

  2. 删除 DSH 源码（WSL 内）：
     wsl -d Ubuntu-24.04 -- rm -rf /home/dsh/dsh

  3. 删除 /agent 目录（WSL 内）：
     wsl -d Ubuntu-24.04 -- sudo rm -rf /agent

  4. 删除桌面快捷方式 "DSH-Web.lnk"

  5. 删除本安装目录

  6. 可选：完全关闭 WSL 功能
     dism /online /disable-feature /featurename:Microsoft-Windows-Subsystem-Linux
